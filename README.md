# SmartECO – AI-Assisted Waste Management

## Start project services


1. Open the command prompt inside project folder

2. In the project folder:

```bash
git pull origin main
```

2. Make sure docker is installed, run the application using ```docker-compose.yml```

```bash
docker compose -f docker-compose.yml up -d
```

After docker is built, the SmartECO application should now be available with the backend and frontend running locally.

```bash
http://localhost:3000
```
